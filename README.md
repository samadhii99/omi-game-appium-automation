# 🎮 Omi Game Appium Automation Framework

Mobile automation testing framework for the **Omi Game Android application** using **Appium, WebdriverIO, TypeScript, and Mocha**, with **Allure reporting** integration.

---

## 🚀 Project Overview

This project automates functional testing of the Omi Game mobile application on Android devices/emulators.  
It ensures core features like app launch and login flow work correctly across builds.

---

## 🛠️ Tech Stack

- Appium
- WebdriverIO
- TypeScript
- Mocha Framework
- Allure Reports
- Android UiAutomator2

---

## 📱 Application Under Test

- Package: `com.ceydigital.oombigame`
- Activity: `com.google.firebase.MessagingUnityPlayerActivity`
- Platform: Android 13
